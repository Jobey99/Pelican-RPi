System User Guide & Diagnostics Index

Go to Tool → Interface Selection:

Select the active hardware interface (e.g. eth0) to bind all scans and listener tools.

Go to Tool → Passive Discovery (Devices list):

Intercepts broadcast packets (ARP, DHCP, mDNS, LLDP) passively. Stealth Mode disables active MAC vendor lookups to ensure the box makes zero noise.

Go to Tool → Active AV Bonjour/mDNS Browser:

Queries the network for Dante audio, Extron control, Kramer VIA, Sennheiser mics, Blustream matrix systems, and AirPlay streaming devices.

Go to Tool → Active Probes (ARP & Ports):

"Sweep Subnet" pings the entire CIDR range via fast ARP requests. "Probe Ports" sweeps standard media/automation ports (HTTP, HTTPS, SSH, PJLink, Crestron, etc.) on the target IP.

Go to Tool → DHCP Server Audit:

Broadcasts a discovery packet to audit Gateway routing, DNS details, lease times, and alert you if rogue DHCP servers exist on this link segment.

Go to Tool → Beacon Mode:

Rapidly toggles the physical RPi link LED at 5Hz to identify this specific box on a crowded equipment rack.

Go to Tool → QoS Link Logger:

Continuously pings the destination target, graphing rolling jitter/latency and exporting logs to CSV format.

Go to Tool → CCTV Camera Inspector:

Discovers local ONVIF cameras and tests standard defaults to audit security credentials and RTSP stream feeds.

Go to Tool → Wi-Fi & System Settings:

Configure the RPi's Wi-Fi connection, choose personalization color profiles, toggle server autostart on reboot, and reboot or shut down the Pi.

Go to Tool → Vulnerability Auditor (Pen Test):

Test wireless segments for security flags like WPA3 encryption, router administration exposures, and default credential leaks. (Access via Settings toggle).

Go to Tool → Commissioning Handover Report:

Runs a complete network check, logs topology results, and generates a client handover report under the ZAVI branding.
